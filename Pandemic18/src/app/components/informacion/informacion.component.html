Reglas del juego

Objetivo:

Controla la propagación de enfermedades en diferentes ciudades mientras mejoras la salud global. Usa tus recursos y personajes estratégicamente para superar los desafíos.

Turnos:

Cada turno, las enfermedades se propagan o disminuyen dependiendo de tus decisiones. Usa tus turnos para curar, investigar o reducir infecciones en las ciudades.

Personajes:

Cada personaje tiene habilidades únicas. Selecciónalos sabiamente para actuar en las ciudades más necesitadas. Asigna tareas como curar o gestionar brotes en una ciudad.

Ciudades:

Las ciudades tienen niveles de infección. Vigila cuáles están más infectadas para priorizar tus esfuerzos. Puedes buscar ciudades por nombre para gestionarlas.

Enfermedades:

Cada enfermedad tiene un tiempo de curación. Si logras curarla, recibirás puntos como recompensa. Las enfermedades pueden reaparecer si no controlas la propagación.

Acciones Disponibles:

Curar Enfermedad: Reduce los niveles de infección. Mover Personaje: Desplázalos entre ciudades para gestionar brotes. Revisar Ciudades: Busca las más afectadas y toma decisiones estratégicas.

Puntuación:

Gana puntos al curar enfermedades y gestionar bien las ciudades. Tu objetivo es lograr la mayor puntuación posible mientras mantienes el mundo bajo control.

Zoom y Navegación:

Usa el zoom para enfocar regiones específicas del mapa. Puedes desplazarte por el mapa con el ratón o tocando la pantalla (en móviles).

Fin del Juego:

El juego termina si las enfermedades se descontrolan o si logras curar todas las ciudades.

¡Buena suerte, estratega! Salva el mundo turno a turno.
